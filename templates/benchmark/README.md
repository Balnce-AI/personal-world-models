# Benchmark template

Status: `TEMPLATE`.

Every benchmark submission must include:

- falsifiable claim and status;
- pinned synthetic/public dataset with digest and license;
- implementation, dependency, prompt/model and hardware identifiers;
- deterministic seed or documented nondeterminism;
- baseline and negative control;
- privacy, provenance, authority and resource metrics;
- repetitions, uncertainty and failure accounting;
- command that regenerates machine-readable results;
- limitations and explicit non-claims.

Never use private PWM data. A capability benchmark does not establish consciousness, safety, authority, portability or production readiness.
