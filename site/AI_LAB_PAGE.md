# AI Lab page — content architecture

## Hero
**What happens when your AI—not somebody else's model of you—can enter the machines around you?**

A Personal World Model is an attempt to give the person an authoritative, portable model of their own world. The Human Projection Layer is how that model can send only what another system needs—without handing over the whole person.

## Sections
1. **The problem** — every system is building another partial theory of you.
2. **The Personal World Model** — memory + relationships + state + intent + authority + space + provenance + uncertainty.
3. **The Human Projection Layer** — minimum necessary representation, bounded purpose, bounded time.
4. **Physical AI** — vehicles, robots, machines; local safety remains local.
5. **The proofs** — executable demos and benchmark results, not animations of imagined capability.
6. **Standards** — HCP, MHS, ROS, COVESA, WoT and the adapter philosophy.
7. **Open research** — deletion, multi-principal authority, spatial privacy, model portability, learning return.
8. **Papers and RFCs** — versioned work with status labels.
9. **Collaborate** — researchers, OEMs, robotics teams, security labs and standards contributors.

The page should visibly badge every result as Implemented / Reference / Experimental / Proposed / Research / Hypothesis.
