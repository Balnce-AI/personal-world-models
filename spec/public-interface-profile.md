# Public Interoperability Profile

This file defines the boundary that should be easiest for other systems to implement without importing Balnce internals.

## Stable public objects

- PWM Object/Relation/Assertion profile
- Projection Request
- Projection Manifest
- Arranger Manifest
- Authority Constraint
- Learning Candidate
- Departure Receipt
- Machine Broadcast
- Capability Mapping Record

## Intentionally not standardized here

- Internal UOR algebra/kernel implementation
- Full PLOG superstructure
- NEP internal layer mechanics
- UHR runtime internals
- Guardian internals
- private model-routing policy
- private Business World Model operational intelligence
- private hypernetwork/distillation machinery

The goal is to open the **interface**, not flatten the implementation.
