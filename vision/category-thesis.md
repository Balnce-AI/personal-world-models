# Category thesis: from personal memory to a personal world model

The near-term personal-AI market is converging on several useful but incomplete ideas:

- portable memory;
- provider memory;
- personal language models;
- local/on-device inference;
- preference protocols;
- agent identity and delegated authority;
- physical-AI capability descriptions;
- robot/vehicle world models;
- edge inference.

The thesis of this repository is that these are **components around a deeper object**.

## The new primitive

A person's AI should not have to reconstruct a theory of them separately inside every provider.

The person should be able to maintain an authoritative model of their own world that knows the difference between:

- what happened and what is true now;
- what the person explicitly said and what a system inferred;
- a preference and a policy;
- a goal and a commitment;
- a relationship and an account record;
- a map and a lived spatial boundary;
- a capability and authority to use it;
- an observation and a trusted fact;
- uncertainty and absence of data.

That object is the **Personal World Model**.

The corresponding interoperability problem is not “sync all memory everywhere.” It is:

> **How can a sovereign world model generate the smallest representation another intelligence needs, bind it to an authorized purpose, and take responsibility for what returns?**

That is the Human Projection Layer.

## Why this is structurally different

A memory product optimizes retrieval.  
A personal SLM optimizes learned behavior/inference.  
A digital twin often optimizes simulation of an asset/person.  
A profile optimizes provider personalization.  
A credential wallet optimizes proofs and claims.  
A robot world model optimizes physical prediction/control.  

A PWM must compose **state, history, evidence, relationships, intent, authority, uncertainty and action** while remaining corrigible and governed by the person.

If this architecture succeeds, the important shift is not a better assistant. It is a computing model in which **human continuity becomes portable across computational bodies**.
