# Evidence ledger

This directory should contain a machine-readable ledger for every public technical claim.

Fields:
- claim ID;
- exact claim;
- domain;
- source URL/document/version;
- primary/secondary/internal;
- status: VERIFIED / SUPPORTED / INFERRED / CONFLICTED / UNVERIFIED / FALSE;
- implementation consequence;
- last reviewed date;
- reviewer;
- falsifier or re-check trigger.

Research synthesis documents are not themselves primary evidence.
