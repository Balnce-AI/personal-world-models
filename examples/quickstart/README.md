# SDK quickstart A-G

Status: `EXPERIMENTAL`. Run from an editable checkout with Python 3.11+.

```sh
python examples/quickstart/a_create.py
python examples/quickstart/b_derive_model.py
python examples/quickstart/c_local_model.py
python examples/quickstart/d_hpl_projection.py
python examples/quickstart/e_possible_world.py
python examples/quickstart/f_custom_adapter.py
python examples/quickstart/g_benchmark.py
```

The sequence creates a PWM, derives and reviews a model, attaches a local inference adapter, negotiates an HPL projection, creates an isolated possible world, loads a namespaced third-party adapter, and runs a matched benchmark. It keeps event, materialization, authorization, projection, hypothetical-world, adapter, and research boundaries visible. It is a reference path, not production authority or persistence.
