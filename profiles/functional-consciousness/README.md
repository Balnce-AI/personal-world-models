# Functional Consciousness Compatibility Profile

**Status:** `RESEARCH`  
**Profile completeness:** source review required before catalog-level compatibility claims

This optional profile maps Frank W. Bergmann's Functional Consciousness (FC) and Functional Self-Model Analysis (FSMA) research into PWM model families. FC is treated as an attributed research input concerning inspectable internal representations, not as PWM's ontology and not as evidence of phenomenal consciousness.

PWM remains broader: self, other actors, relationships, world state, time, uncertainty, authority, provenance, possible worlds, and models-of-models remain first-class. No Functional Consciousness Score is implemented or represented as a validated consciousness metric.

The DOI metadata verifies the cited preprint and its abstract. The primary catalog table was not available through the source material reviewed for this implementation, so `self-models.json` records the expected catalog count and blocks enumeration-dependent evaluation. This deliberate incompleteness prevents invented labels from being attributed to Bergmann.
