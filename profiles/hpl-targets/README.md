# Experimental HPL target profiles

These profiles are illustrative, capability-first interoperability examples. They are not device claims, deployment policy, production authority, or safety certification. A target advertises a fresh capability manifest separately; discovery never grants authority. Deployments may add capabilities and stricter field policy without treating the target class as permission.

Every example explicitly identifies fields that may and may not cross the projection boundary. All records have `canonicalV2Effect: NONE`.
