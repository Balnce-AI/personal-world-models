# Roadmap

## Wave 0 — Evidence and canon lock
- Evidence ledger, terminology map, status linting, ADRs.

## Wave 1 — PWM reference core
- Temporal graph, assertions, provenance references, deterministic materialization, conflicts and supersession.

## Wave 2 — HPL projection compiler
- Purpose binding, minimization, policy/authority evaluation, spatial filtering, provenance trace.

## Wave 3 — Arranger lifecycle
- Signing, recipient/runtime binding, TTL, anti-replay, revocation, learning return, departure receipts.

## Wave 4 — Interoperability
- HCP profile; ROS 2, COVESA/VSS/VISS and WoT mappings; MHS mapping only after normative source review.

## Wave 5 — Embodiment simulations
- Home robot, lab automation, personal vehicle, rental/fleet vehicle, support/diagnostics.

## Wave 6 — Benchmarks
- HPL-CONTEXT, HPL-AUTH, HPL-SPATIAL, HPL-RESIDUE, HPL-LEAKAGE, HPL-DRIFT, HPL-HANDOFF.

## Wave 7 — Research/standards release
- Position papers, reproducibility package, RFC process, standards profiles.
