# Paper 02 — Human Projection Layer

**Status:** PROPOSED

## Working thesis
Foreign AI and physical systems can be useful without owning a full permanent model of the person if the source world model can compile bounded, purpose- and recipient-specific representations with explicit authority and lifecycle evidence.

## Contributions to target
- projection operator and artifact taxonomy;
- multi-principal authority composition;
- recipient/runtime binding;
- physical safety separation;
- learning return;
- departure assurance levels;
- software/robot/vehicle demonstrations;
- HPL benchmark suite.
