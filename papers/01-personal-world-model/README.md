# Paper 01 — Personal World Models

**Status:** PROPOSED

## Working thesis
A personal AI needs more than retrieval memory: it needs a user-governed world state that preserves evidence lineage, temporal validity, conflicting beliefs, relationships, intent, policy, authority, uncertainty and correction.

## Contributions to target
1. Formal PWM object/state model.
2. Event/provenance-backed materialization.
3. Distinction between observation, belief, fact, policy, preference and intent.
4. Minimum public interoperability profile.
5. Benchmarks comparing world-state tasks against memory-only baselines.
6. Security/correction/portability analysis.

## Falsifier
If memory-only/provider-native systems consistently equal or exceed the PWM on utility, correction cost, portability, provenance and disclosure control, the richer primitive must be simplified.
