# Public ADRs

Public architecture decision records explain durable repository-level choices without exposing private deployment details. Statuses are `PROPOSED`, `ACCEPTED`, `SUPERSEDED`, or `REJECTED`. Copy `templates/adr/ADR-TEMPLATE.md`, use the next four-digit number, link evidence and alternatives, include security/privacy and migration effects, and name any superseded ADR.

These seed ADRs are public-safe summaries. They do not supersede private production decisions.
