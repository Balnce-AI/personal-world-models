# Glossary

**Personal World Model (PWM)** — sovereign, temporal, provenance-bearing semantic model of a person and their lived world.

**Human Projection Layer (HPL)** — policy-governed compiler/lifecycle system for bounded representations derived from a PWM/BWM.

**Projection** — minimum purpose/recipient-bound representation emitted by HPL.

**Arranger** — signed/scoped/revocable crystallized transfer artifact. In Balnce canon it is transported by a Hyperframe; it is not the carrier itself.

**Hyperframe** — canonical Balnce polymorphic carrier/envelope. The public repo does not attempt to reimplement full private Hyperframe behavior.

**Covenant Atom** — canonical Balnce primitive behind consent, permissions, credentials, commitments and delegation-style projections; public authority constraints are an interoperability profile, not a replacement.

**PLOG** — Balnce provenance superstructure; already Merkle-DAG based. Public reference events are deliberately smaller than the private canonical implementation.

**UOR** — Universal Object Reference algebraic/content-address substrate used by Balnce canon. Public reference SHA-256 IDs are not a UOR substitute.

**Crystallization Gradient** — interpreted → contextual → programmatic → adapter → distilled.

**NEP** — Neural Engine Protocol.

**UHR** — Universal Host Runtime.

**Web0** — agent/network layer in which people, businesses, agents and machines can discover, coordinate, negotiate and exchange under authority.
